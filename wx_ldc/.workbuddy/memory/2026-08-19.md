## 2026-08-23 ESP32 实测排障
- 用户用 Thonny Run 在板子（MicroPython v1.26.0, Generic ESP32）上跑，报 `ConnectionError: Device not configured`（USB 掉线）+ KeyboardInterrupt。判定：Thonny 后台探测 REPL + BLE 扫描冲突，且 USB 供电不稳。
- 加固：① `BmsBle.__init__` 拆分致命/可容忍异常并抛 BleError，main.py 加初始化重试；② 扫描循环只解析新设备（_scan_keys + _parsed_count），降低占空比（interval 50ms/window 30ms），gap_scan(None) 加 try；③ `scan()` 支持 `progress_cb`，每 2s 打印「扫描中...已发现 N 台设备」。
- 建议用户：外部 5V 供电、换 USB 线/口；上传后关掉 Thonny，用 mpremote/screen 看串口；已写入 README 常见问题。
